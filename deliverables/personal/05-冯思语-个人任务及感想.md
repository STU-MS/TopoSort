## 三、完成的工作

### 3.1 T5 界面壳（核心代码）

实现了 `app/ui/` 六个文件：

- **[`main_window.py`](https://github.com/STU-MS/TopoSort/blob/master/app/ui/main_window.py)**——三栏 `QSplitter` 主窗口（输入区 / 图画板 / 泳道+结果流）+ 顶部控制条
  + 底部状态行；提供契约要求的公共 API：`set_input` / `input_text` / `click_start` /
  `results` / `error_text` / `save_to` / `load_from`。
- **[`control_bar.py`](https://github.com/STU-MS/TopoSort/blob/master/app/ui/control_bar.py)**——开始 / 暂停 / 单步 / 跳完 + 速度滑块（80–1200 ms/拍，右移=更快）。
- **[`input_panel.py`](https://github.com/STU-MS/TopoSort/blob/master/app/ui/input_panel.py)**——关系文本框 + 打开/保存/清空。
- **[`lanes.py`](https://github.com/STU-MS/TopoSort/blob/master/app/ui/lanes.py)**——泳道面板，上限 8 条，超出不建行但照常计数并提示。
- **[`results.py`](https://github.com/STU-MS/TopoSort/blob/master/app/ui/results.py)**——结果流，支持导出 txt / 复制全部。
- **`__init__.py`**——导出 `MainWindow`、`run` 程序入口。

### 3.2 契约优先 + 优雅降级

我开工时 T2/T3/T4 三个模块还没合并，它们的公共 API 都在抛 `NotImplementedError`。我选择
**照契约编码、捕获未实现异常后优雅降级**，而不是在界面里塞临时假数据——同一份代码在模块
合并后自动转真、零返工，降级时状态行也明示"某模块尚未完成"，不会误导用户。这个取舍连同
其余 7 项实现决定一起留档在 [`evidence/decisions/2026-09-20-界面壳实现决定.md`](https://github.com/STU-MS/TopoSort/blob/master/evidence/decisions/2026-09-20-%E7%95%8C%E9%9D%A2%E5%A3%B3%E5%AE%9E%E7%8E%B0%E5%86%B3%E5%AE%9A.md)。

### 3.3 截图工具与素材

写了 [`tools/shoot.py`](https://github.com/STU-MS/TopoSort/blob/master/tools/shoot.py)：用 Qt 自带的 `QWidget.grab()` 把窗口重绘成 PNG，三端行为一致、不受
遮挡；命名自动符合 `功能名-YYYYMMDD-N.png` 且保证 >20KB，直接通过 [`tools/check_docs.py`](https://github.com/STU-MS/TopoSort/blob/master/tools/check_docs.py)
的机械检查。脚本对未就绪模块打印"跳过"、**绝不伪造图片**。最终为报告提供了 6 张界面截图
（初始 / 输入完成 / 结果流 / 解析错误 / 环检测 / 泳道并推）。

## 四、遇到的问题与解决

| 问题 | 我的处理 |
|---|---|
| 依赖未就绪时界面壳做不下去 | 契约优先 + 优雅降级，不造假数据 |
| 降级文案里的"T2"数字会误命中"第 2 行"的断言 | 去掉版本号，改成"models 模块尚未完成"——测试因为正确的原因变绿 |
| Windows GBK 控制台打印中文文件名崩溃 | `sys.stdout.reconfigure(encoding="utf-8")` 兜底 |
| PyPI 官方源 17.5KB/s，装依赖卡了快一小时 | 换清华源（10.3MB/s），并在提交前还原 [`uv.lock`](https://github.com/STU-MS/TopoSort/blob/master/uv.lock)，避免镜像 URL 污染锁文件 |
| 改输入后画布还停在上一张图 | 每次"开始"先卸载旧画布再重建（`_drop_board()`） |
| 启动时就谎报"渲染模块尚未完成" | 抽空闲态提示，渲染层异常单独兜底、不拖垮结果流 |

## 五、收获与感想

1. **契约是团队协作的锚**。T1 预埋的验收测试让我在别人模块没完成时也能独立推进——先读
   契约、照契约写，比等所有人到齐再动手高效得多；模块一合并我的代码就直接转真，几乎没返工。
2. **"因为错误的原因变绿"比红着更危险**。我写的降级文案里一个数字"2"就误命中行号断言，
   测试是过了，但断言根本没测到它想测的东西。这让我对"测试绿 ≠ 功能对"有了切身体会。
3. **留痕不是负担，是救命的**。每做一个决定就写进 `evidence/decisions/`、每出一个可见
   效果就截图，到了写报告这步，素材是现成的，而不是回头补回忆。
4. **跨平台不是口号**。Windows 的 GBK 控制台、路径分隔符、`newline`，这些"小事"各坑了我
   一次，也让我理解了为什么项目把 `pathlib`、显式 `encoding='utf-8'` 定成红线。
