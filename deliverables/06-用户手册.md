## 1. 这个软件是做什么的

你手上有一堆"谁必须先于谁"的约束，比如课程先修关系 `<A,C>` 表示"上 C 之前必须先上 A"。
本软件帮你做三件事：

1. **画出来**：把约束关系画成有向图，并按依赖层次分层摆放，一眼看清结构。
2. **演出来**：用动画演示"排出合法顺序"的全过程——哪些节点现在可以选、这一步选了谁、
   在哪里出现了多种选择从而派生出多条路线。
3. **算出来**：列出**所有**合法的排列顺序（不只一条），并在约束互相矛盾（出现环）时
   明确告诉你哪几个节点矛盾了。

## 2. 安装与启动

软件以**单文件可执行程序**发布，目标电脑**无需安装 Python 或任何依赖**。

### 2.1 Windows

1. 解压交付压缩包，进入 `windows/` 目录。
2. 双击 `TopoSort.exe` 即可运行。
3. 首次运行若被 SmartScreen 拦截，点"更多信息"→"仍要运行"（程序未做商业代码签名）。

### 2.2 macOS

1. 进入 `macos/` 目录，双击 `TopoSort.app`。
2. 首次打开若提示"无法验证开发者"，在"系统设置 → 隐私与安全性"中点"仍要打开"。

### 2.3 Linux

1. 进入 `linux/` 目录，给可执行文件加上执行权限：`chmod +x TopoSort`
2. 运行：`./TopoSort`

### 2.4 从源码运行（开发者）

```bash
uv sync                    # 按 uv.lock 安装依赖
uv run python app/main.py  # 启动
```

> 本项目统一使用 `uv` 管理依赖，请勿使用 `pip install` 直接安装。

## 5. 功能详解

### 5.1 输入区

| 按钮 | 作用 |
|---|---|
| 打开… | 从文本文件读入关系（UTF-8 编码） |
| 保存… | 把当前输入框内容存成文本文件 |
| 清空 | 清空输入框 |

一行一条关系，**行内不要写多个关系**。空白行会被自动跳过。

### 5.2 控制条

| 控件 | 作用 |
|---|---|
| 开始 | 解析输入并开始演示。输入的格式或约束有问题时，会在底部状态行给出红色提示 |
| 暂停 | 暂停动画。按钮呈按下状态表示已暂停；再点一次继续 |
| 单步 | 暂停状态下，一次只推进一拍，便于讲解和观察 |
| 跳完 | 跳过动画，直接得到最终结果（结果本来就会立刻算好，此按钮只影响动画） |
| 速度 | 滑块右移加快、左移放慢，右侧实时显示"每拍毫秒数"（默认 400） |

### 5.3 图画板

节点按依赖层次从左到右排布：没有任何先修要求的节点在最左，其后依次加深。
鼠标滚轮缩放、按住拖动平移。

节点颜色含义（**待集成完成后补图**）：

| 状态 | 含义 |
|---|---|
| 普通 | 尚未轮到 |
| 高亮（就绪） | 当前所有先修要求都已满足，可以选了 |
| 选中（活跃） | 本拍被选中的节点 |
| 变淡（幽灵） | 已被排入结果，退出后续计算 |
| 卡住 | 处于环上，永远等不到 |

### 5.4 泳道

当某一步出现**多个可选的节点**时，软件会分出多条并行路线同时推进，每条路线在泳道区
占一行，显示它已经排入的节点序列。行尾显示"完成：A B C D E"表示这条路线已经排完。

泳道最多同时显示 8 条。超出上限的路线**不会单独展示，但结果照常计入**，界面会提示还有
多少条在后台计数。

### 5.5 结果流

每条结果一行，节点之间用空格分隔，例如 `A B C D E`。列表上方的标题实时显示当前共有多
少条合法顺序。

结果过多时会按上限截断（默认最多 2000 条），标题显示的是**实际列出的条数**。

## 6. 输入格式与容错

软件对输入相当宽容，下列写法都能正确识别：

| 写法 | 是否接受 | 说明 |
|---|---|---|
| `<A,C>` | 接受 | 标准写法 |
| `A,C` | 接受 | 省略尖括号 |
| 全角括号 `（A,C）` | 接受 | 中英文标点混用也能识别 |
| 空白行 | 接受 | 自动跳过 |
| `<A,C>` 重复写多次 | 接受 | 自动去重，不影响结果 |
| `<A,A>` | 不接受 | 自己先于自己，属非法输入，会报错 |
| `<A>` | 不接受 | 缺少另一半，会报错 |

**节点名**可以是任意不含逗号、尖括号的词，例如 `<数学分析,数据结构>` 或 `<C1,C2>`。

## 7. 出错怎么办

所有错误都会以**红底提示**出现在窗口底部状态行，窗口不会崩溃，输入内容也不会丢失。

### 7.1 输入格式错误

提示形如：

> 解析错误：第 2 行解析失败：每行必须包含且仅包含一个逗号（原文：'<A>'）

[![第 2 行格式错误时，窗口底部给出含行号的红色提示](../evidence/screenshots/主窗口-解析错误提示-20260920-1.png)](https://github.com/STU-MS/TopoSort/blob/master/evidence/screenshots/%E4%B8%BB%E7%AA%97%E5%8F%A3-%E8%A7%A3%E6%9E%90%E9%94%99%E8%AF%AF%E6%8F%90%E7%A4%BA-20260920-1.png)

**处理方法**：按提示的行号回到输入框第 2 行修改。行号从 1 开始数，空行也计入行号。

### 7.2 约束出现环

提示形如：

> 检测到环：{A、B} 相互依赖，不存在拓扑序

[![输入 <A,B> 与 <B,A> 时，底部提示检测到环并列出环上节点](../evidence/screenshots/主窗口-环检测提示-20260920-1.png)](https://github.com/STU-MS/TopoSort/blob/master/evidence/screenshots/%E4%B8%BB%E7%AA%97%E5%8F%A3-%E7%8E%AF%E6%A3%80%E6%B5%8B%E6%8F%90%E7%A4%BA-20260920-1.png)

**含义**：A 要求先于 B，B 又要求先于 A，二者互锁，任何顺序都无法同时满足——因此
**不存在**拓扑排序，这不是软件算不出来，而是约束本身无解。

**处理方法**：检查提示中列出的这些节点之间的关系，找出写错的那一条并删除或改正。

## 8. 常见问题

**Q：为什么"开始"是灰的 / 点不动？**
A：演示进行中"开始"会禁用，先点"跳完"或等演示结束。

**Q：结果条数是不是越多越好？**
A：不一定。条数反映的是约束的松散程度：约束越多、越严，合法顺序越少；如果约束构成一条
完整的链，就只会有一条结果。

**Q：大图很卡怎么办？**
A：把速度滑块拖到最快，或直接点"跳完"跳过动画。结果是在点"开始"的瞬间就算好的，
动画只是演示，跳过不影响结果。

**Q：能算多大规模的图？**
A：图本身可以很大；但**结果条数**在分叉多时会呈爆炸式增长，软件会按上限截断以保证
界面不卡死。

**Q：换行符、编码会不会导致乱码？**
A：软件读写一律使用 UTF-8，并在 Windows / macOS / Linux 上行为一致，不会因换行符
不同而出错。

## 9. 卸载

本软件为绿色单文件程序，**直接删除可执行文件即可**，不写注册表、不留配置文件。
用户自己保存的关系文件与导出结果需自行删除。
