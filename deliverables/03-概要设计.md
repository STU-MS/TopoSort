## 1. 系统概述

拓扑排序动画演示器：输入 `<a,b>` 依赖关系文本，解析为有向无环图（或检出环），
用动画演示 Kahn 算法逐步消点的过程，并枚举全部合法拓扑序。技术栈
Python 3 + PySide6 + PyInstaller（单文件），三端通用（Windows / macOS / Linux）。

## 2. 架构分层

```
┌─────────────────────────────────────────────────────┐
│ ui/      界面层：主窗口/输入面板/控制条/泳道面板/结果   │  依赖 scene、events、models
├─────────────────────────────────────────────────────┤
│ scene/   渲染层：画布/动画/候选池；只认事件，不懂算法   │  依赖 events（仅类型）
├─────────────────────────────────────────────────────┤
│ events/  事件层：算法→确定性事件流 + 伪并发时间线      │  依赖 models（仅 Graph 数据）
├─────────────────────────────────────────────────────┤
│ models/  逻辑层：解析/图结构/Kahn/全序枚举/环检测      │  零上层依赖
└─────────────────────────────────────────────────────┘
```

**依赖单向规则**（CI 强制）：`ui → scene → events → models`，禁止反向与跨层；
`models` 与 `events` 零 Qt 依赖（`import` 后 `sys.modules` 不得出现 PySide6/PyQt）。

## 3. 模块划分与职责

| 模块 | 文件 | 职责 |
|---|---|---|
| models | parser.py | `<a,b>` 文本解析，宽容变体，错误带行号 |
| models | graph.py | 不可变图结构、最长路径分层、环检测 |
| models | enumerator.py | Kahn 全序枚举（显式栈回溯）、计数、截断 |
| events | protocol.py | StepEvent 六类事件唯一定义 |
| events | player.py | Kahn 步进内核：显式分支工作队列 → 确定性事件流 |
| events | timeline.py | 伪并发调度：tick 交错、暂停/单步/调速、泳道上限 |
| scene | board.py / effects.py / pool.py | 图元布局、动画、候选池芯片、PNG 导出 |
| ui | main_window.py 等 | 组装与信号槽、输入/控制/结果呈现 |

## 4. 关键接口契约（摘要，全文见 evidence/decisions/2026-09-15-契约定案.md）

- **输入**：每行 `<a,b>`；重复边去重；自环非法；错误 `ParseError(lineno, line, reason)`。
- **事件协议**：Enqueue / Consume / Fork / Complete / DeadEnd / CycleFound，
  字段与语义见契约 §3；确定性：同输入事件序列逐项相等。
- **时间线**：每 tick 按 branch_id 升序交错推进活跃分支各一步；泳道上限
  lane_limit（默认 8），溢出分支不可视化但 Complete 照发仍计数；状态机
  running/paused/finished。
- **渲染**：只消费 `layers` 与 StepEvent，禁止调用算法函数。
- **标准基准图**：`<A,C> <A,E> <B,C> <C,D>` 恰 7 条合法序
  （2026-09-19 修正，见 evidence/decisions/2026-09-19-标准图数量修正.md）。

## 5. 运行数据流

```
用户输入文本 → parse() → Graph ─┬─ layers() ──────────→ 画布静态布局
                               └─ TopoPlayer ─→ Timeline ─→ 每拍事件列表
                                      │                      ↓
                                      │               scene.apply_event()
                                      ↓                      ↓
                              Complete 累积 ─────────→ 结果列表/导出
```

## 6. 跨平台与 CI 策略

- 路径一律 `pathlib`；文件读写显式 `encoding='utf-8'`；写文件 `newline=''`。
- GitHub Actions 三平台矩阵（ubuntu/macos/windows）；L1 机械红线（契约测试
  +文档检查）必须绿，L2 模块测试 `continue-on-error` 作为完成度路标。
- Windows 产物由 Actions windows-latest 自动构建并附 SHA256。
