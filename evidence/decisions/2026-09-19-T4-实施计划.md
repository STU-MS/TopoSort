# T4 渲染场景实施计划

- 关联任务：T4 `scene`（Issue #5）
- 日期：2026-09-19
- 参与人：项目用户、Codex
- 状态：已实施，待与 T3/T5 进入 T6 集成

## 目标

实现只消费节点、边、`layers` 和 `StepEvent` 的 PySide6 渲染层，包括分层拓扑图、候选池、事件状态动画、平移缩放以及图/候选池 PNG 导出。

## 实施顺序

1. 扩充 `app/tests/test_scene.py`，先覆盖节点状态、DeadEnd、Fork/Complete 无副作用、非法边、CandidatePool 集合语义、边淡化和两个 PNG 导出。
2. 在 `effects.py` 集中实现 `QPropertyAnimation` 工厂，保持 `GHOST_MS=300`、`PULSE_MS=250`、`EDGE_DIM_MS=200`。
3. 在 `board.py` 实现 `GraphBoard(QGraphicsView)`、稳定分层布局、事件消费、平移缩放和 PNG 导出。
4. 在 `pool.py` 实现 `CandidatePool(QWidget)`、候选芯片替换/消费动画和 PNG 导出。
5. 用 `tools/capture_t4_screenshots.py` 生成 ready、active、ghost+边淡化、stuck 四类截图。
6. 使用 `uv run pytest app/tests/test_contracts.py app/tests/test_scene.py -q` 验证 T4 与基础契约；完整测试中的 T2/T3/T5 存根失败单独记录，不扩展 T4 范围。

## 边界

- 不导入 `app.models`，不实现拓扑算法。
- 不实现 Timeline、泳道、结果列表和 MainWindow 接线。
- T5 负责将事件扇出给 `GraphBoard` 和 `CandidatePool`。
- 路径使用 `pathlib`，Python 命令只通过 uv 执行。

## 验收

- T4 pytest-qt 用例全部通过。
- `GraphBoard` 和 `CandidatePool` 均能导出非空 PNG。
- `evidence/screenshots/` 中具备四类非空效果截图。
- `app.models` / `app.events` 保持零 Qt 依赖。
