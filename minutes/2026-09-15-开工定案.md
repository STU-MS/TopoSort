## 会议内容

本次为正式开工会议，逐项落定技术栈、工程管理、任务拆分与模块间契约，对应里程碑 M0（T1 骨架合入）。

1. **技术栈定案（组长 HandyWote）**。
   - 定案：**Python 3 + PySide6（QGraphicsView）+ 算法自研 + PyInstaller `--onefile`**。留档 `evidence/decisions/2026-09-15-技术栈定案.md`（issue #1）。
   - 淘汰候选与理由：C# WinForms + MSAGL（GViewer 仅 Windows）、C# Avalonia + AvaloniaGraphControl（无过渡动画）、Java + GraphStream（jpackage 出文件夹、力导向丢失分层语义）。
   - 关键洞察：产品采用「固定分层布局 + 节点消耗渐隐」，不需力导向重排，故分层布局自算（层号 = 从源点最长路径，拓扑排序副产品）≤40 行；`QPropertyAnimation` 提供可控动画。
   - 红线：算法（Kahn、全序枚举、环检测）必须自研，库仅用于 GUI 与打包。

2. **三端通用硬性要求确认（组长 HandyWote）**。
   - 会议将产品目标由「自己电脑验收」修正为**三端通用（Windows / macOS / Linux）**：CI 三平台矩阵、打包出三份产物、Windows 产物走 GitHub Actions 构建。留档见 09-15 提交 `docs: 修正为三端通用` 与 `2026-09-15-技术栈定案.md`。
   - 跨平台红线：路径用 `pathlib`、文件读写显式 `encoding='utf-8'`、写文件用 `newline=''`、禁止平台专属调用。

3. **工程管理定案（组长 HandyWote）**。
   - 引入 **uv** 统一工程管理：`pyproject.toml` 为依赖唯一入口、`uv.lock` 一并提交；装环境 `uv sync`、跑程序 `uv run python app/main.py`、跑测试 `uv run pytest`。提交：`docs: 引入 uv 统一工程管理 (pyproject+uv.lock+.gitignore)`。
   - 建立项目规范与留档体系：`AGENTS.md`（最高规范）、`CONTRIBUTING.md`、决策留档与会议模板（提交：`docs: 建立项目规范与留档体系`）。

4. **任务拆分总表定案（组长 HandyWote）**。
   - 拆分 9 个任务并给出依赖图与里程碑。留档 `evidence/decisions/2026-09-15-任务拆分总表.md`：
     - T1 基建（骨架 / CI / 契约）可立即开工；T2 算法内核、T3 事件引擎、T4 渲染场景、T5 界面壳依赖 T1 并行；T6 集成联调依赖 T2+T3+T4+T5；T7 打包发布依赖 T6；T8 交付文档、T9 测试数据与开发并行。
   - 模块主责确认：T2 → Asukadaisiki（models）、T3 → xiaoliei（events）、T4 → HanXuXie（scene）、T5 → Frieda-Feng（ui）。
   - 里程碑：M0 09-15 T1 合入；M1 09-19 T2–T5 验收；M2 09-20～21 T6 集成 + 中期检查；M3 09-25 文档齐稿；M4 09-26～28 打包组装与提交。
   - 留档提交：`docs: 任务拆分总表(9个任务+依赖图+里程碑), AGENTS.md 更新包结构`。

5. **接口契约定案（组长 HandyWote）**。
   - 定案模块间最高接口契约，留档 `evidence/decisions/2026-09-15-契约定案.md`（issue #2）：
     - **输入格式**：每行 `<a,b>`，宽容变体（空白行、全角括号、缺尖括号、`，`）；重复边去重、自环 `<a,a>` 非法；非法行抛 `ParseError(lineno, line, reason)`，lineno 从 1 计；UTF-8 编码。
     - **测试数据**：`evidence/test-data/` 下「编号-描述」成对的输入文件与期望文件（JSON：`orders` / `orders_capped` + `count` / `cycle_nodes` / `parse_error_lineno`），测试代码只读文件不内嵌图数据（conftest 标准图常量除外）。
     - **事件协议**：以 `app/events/protocol.py` 为唯一权威，定义 Enqueue / Consume / Fork / Complete / DeadEnd / CycleFound 六个事件及字段；确定性契约——同输入事件序列逐项相等，`order` 用 tuple；`branch_id` 从 0 起、Fork 递增。
     - **伪并发时间线**：每拍按 `branch_id` 升序交错推进活跃分支各一步，返回本拍事件列表；`lane_limit` 默认 8，溢出分支不产生可视化事件但仍计数（Complete 照发）；状态机 `running → paused → running → … → finished`；`tick_ms` 默认 400。

6. **T1 基建实施（组长 HandyWote）**。
   - 会议后当日完成 T1 并合入 master：包骨架 `app/{models,events,scene,ui}/`、契约测试预埋（5 节点标准图 → 合法序、事件流确定性、导入 models 不得带入 PySide6、UI offscreen 冒烟）、PR 模板 DoD 清单、CI 三平台矩阵、`tools/check_docs.py`。提交：`feat: T1 包骨架+契约测试预埋+契约定稿归档`、`feat: 验收基建——PR模板+CI+check_docs工具`。
   - CI 采用两层判定：L1 机械红线必须绿 + L2 模块红测试 `continue-on-error` 作路标（提交：`feat(ci): 拆两层判定`）；同时修复 Linux runner 装 Qt 系统库以解决 pytest-qt INTERNALERROR（提交：`fix(ci): Linux runner 安装 Qt 系统库`）。
